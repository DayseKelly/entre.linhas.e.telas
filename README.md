# Entre-linhas-e-telas

## Campi do IF Baiano

O cadastro oferece os 14 campi em funcionamento do IF Baiano, cadastrados pela migração do banco: Alagoinhas, Bom Jesus da Lapa, Catu, Governador Mangabeira, Guanambi, Itaberaba, Itapetinga, Santa Inês, Senhor do Bonfim, Serrinha, Teixeira de Freitas, Uruçuca, Valença e Xique-Xique. A lista segue o [portal oficial do IF Baiano](https://www.ifbaiano.edu.br/portal/).
